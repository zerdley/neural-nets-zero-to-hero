# Neural Networks: Zero to Hero

This repository holds all the code from me following Andrej Karpathy's "Neural Networks: Zero to Hero" course, which builds from a basic understanding of code and calculus/linear algebra to building different neural nets from scratch up to building langauge models like GPT.

Each directory here contains the jupyter notebook from me following the video and a jupyter notebook from me doing the exercises for each lesson. AI was just used to validate answers and not to generate any code here. To use these, you'll need uv installed, and you can run `uv sync` and select the resulting .venv kernel in the jupyter notebook when you open it.
